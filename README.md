 Ansible Automation 

A powerful IT automation tool used for server configuration, software provisioning, and application deployment.

How It Works

- Runs Ansible from inside a Docker container
- Targets the host (localhost) or fake servers
- Performs tasks like installing packages, creating users, checking disk, etc.
